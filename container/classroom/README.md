# 课堂管理

管理员在 `/admin/` 登录，通过学生列表添加姓名、复制专属链接、只读查看
终端或明确进入协助模式。学生链接为 `/w/<编号>/#t=...`，学生不选择工作区。
文件面板默认收起，常用操作只有「我的项目、上传、下载」。
文件面板按「项目文件、上传资料、下载记录」分类，支持文件名/文件夹搜索与
类型筛选；每次显示 100 项，可继续加载。上传成功后自动展示上传资料。
上传资料按项目内 `uploads/` 目录区分，其他可导出文件归为项目文件。
下载记录按学生 ID 保存在当前浏览器，最多 50 条，并按当前项目显示；记录的是
交给浏览器的下载请求，不是历史文件备份，再次下载获取服务器上的最新文件。
顶部 ☀ / ☾ 可切换整个工作区的浅色与深色，包含终端、文件面板和弹窗。
选择按学生 ID 保存在当前浏览器，同一学生的多个标签页同步；其他浏览器独立。
未手动选择时继续跟随 agent 主题。手动选择对终端画面做明暗转换，不改写
agent 配置，不输入命令或重启会话；终端图片和自定义颜色也会随画面转换。

## 部署

需要现有 Linux Docker 主机、Node 22 和 Caddy。管理服务在宿主机运行，
监听 `127.0.0.1:17700`。Docker 控制能力只在宿主服务，学生容器不挂载
Docker socket。`dcw-classroom.service` 是 dataclue.cn 使用的配置。

1. 构建 `dc-workspace:0.2.14-classroom`，使用本仓库 `container/Dockerfile`。
2. 将本目录的 mjs、admin.html 和 Node 可执行文件放到 `/opt/dc-terminal/classroom`。
3. 从受信构建镜像复制 `/usr/local/share/dcw/index.html` 到同目录 `terminal.html`，
   属主 root，学生不可写。管理服务只提供这份固定终端页面，不转发学生进程
   提供的 HTML。数据端点强制 JSON/附件类型并禁止浏览器执行。
4. 安装 systemd unit。首次运行在 `/var/lib/dcw-classroom/admin-password`
   生成管理密码，文件仅管理员可读；会话与学生链接保存在同目录的私有状态文件。
5. Caddy 将整个站点转发到 17700，保留 TLS；不要留下同域名上直接转发
   学生 HTML 的路径。终端 HTTP/WebSocket 均由管理服务逐次检查身份。

配置 `CLASSROOM_LEGACY_CONTAINER=dcw-workspace-1` 可接入原共享工作区。
首次接入沿用原访问链接，此后复制/重置/停用链接均在管理台完成。共享
工作区仍标为共享，原文件保留。共享容器不支持页面一键停止，避免影响旧课堂；
管理员可以在协助 UI 内结束具体项目。

## 工作区与账号

每名学生创建独立 state、Claude、Codex、work 命名卷，限制 3 GiB 内存，
无额外 swap，最多 512 个进程。停止和重开保留卷，无删除学生或删除卷按钮。
停止前依次保存并结束项目；失败不停止整个容器，已停止的会话可以重新打开。
独立学生点击「结束」也会保存并停止工作区，释放运行名额；再次打开链接可以继续。
这里没有跨机器备份或硬磁盘配额，磁盘用量在管理页显示。

默认运行上限按宿主总内存减去 1 GiB 预留后除以 3 GiB 计算，原共享容器和
其他管理实例启动的学生容器一起计数。dataclue.cn 当前为同时 2 个工作区。
记录可先创建，首次打开时启动；名额已满时提示联系老师，不暗中超额分配。

新工作区不复制老师或其他学生的 AI 密钥。老师首次启动后通过「协助」配置
该学生的 AI 账号，再发送链接。已有一个运行会话时，重新打开会自动进入该
会话；多个会话时保留选择界面。关闭浏览器不会停止 AI，会话与作品继续保留。

进入查看或协助后，工作区自动占满浏览器窗口；顶部保留返回、学生切换与协助控制。
管理员默认仅调用 List/Screen 读取终端快照；协助开启 45 秒租约，页面每
15 秒续约。结束、过期、退出或重置链接会关闭协助连接。学生每 5 秒看到
协助提示。只读查看不会发送按键、调整学生会话尺寸或修改文件。

## 验证

`node --test container/classroom/server.test.mjs container/classroom/admin-ui.test.cjs`
验证角色和学生隔离、来源检查、只读 API、协助、撤销链接、持久化状态、
受信 HTML 边界、强制响应类型和管理页交互。

`PLAYWRIGHT_MODULE=<playwright路径> node container/tests/project-panel.cjs`
验证学生工具栏、上传/下载、错误、手机抽屉、路由前缀、协助提示与焦点。

发布作品到 ai.tzspace.cn 尚未接入。后续由统一发布服务处理身份、预览、
版本和发布凭据，agent 可共用发布规则；不向每个 agent 分发站点管理员凭据。
