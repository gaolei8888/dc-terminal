A board for coding agents. Start a few, let them work in separate projects, close the terminal. Come back, find one made a mess, press one key and it's gone. 一块给 coding agent 用的板子。开几个，让它们在各自的项目里干活，然后把终端关掉。 回来发现哪个搞砸了，按一个键，就当没发生过。

the deal前提

It never asks “is this okay?” 它从来不问「这样可以吗？」

Precisely because you can always take it back. Before every turn, dct takes a hidden snapshot of the project. That is what makes it safe to turn permission prompts off entirely: agents don't stall waiting for you to say yes, and whatever they break is one keypress away from undone. 正因为你随时能收回来。每一轮开始之前，dct 会给项目拍一张隐藏快照。 正是这一点让「把所有确认提示关掉」变得安全：agent 不会停在那儿等你点同意， 而它弄坏的任何东西，一个键就能撤回来。

Snapshots go through git, but on the side of git you never look at. Your branches, your staging area and your git log stay clean. 快照走的是 git，但走的是你从来不看的那一侧。你的分支、暂存区、git log 全都干干净净。

the daemon守护进程

Sessions outlive the terminal 会话比终端活得久

The first run starts a background daemon, and the daemon is the product. Close the window, shut the lid, come back tomorrow — the sessions are still running exactly where they were. dct itself is just the window you reattach with. 第一次运行会起一个后台守护进程，而守护进程才是这个产品本身。 关窗口、合上盖子、明天再来——会话还在原地跑着。dct 只是你重新贴上去的那扇窗。

the board看板

One keypress per thing you'd want 想做的每件事都是一个键

Every project remembers its own last agent: press n in one and you get claude, press it in another and you get codex — and the bottom bar names which one before you press anything. 每个项目各自记着上次用的 agent：在这个项目里按 n 开出 claude， 在那个项目里按 n 开出 codex——按下去之前，底栏就写着这一下会开出谁。

One door, including the ones that don't work yet 一扇门，连现在用不了的那几个也在里面

Press N and you get all nine. The ones this machine can't run are greyed out with the reason, and picking one takes you toward fixing it instead of just saying no: not installed opens a session running the installer, so you watch it work; no key opens a box to paste into, with a link to wherever you get one. 按 N，九个全在。这台机器上跑不了的那几个是灰的，并且写着原因； 选中它不是碰一鼻子灰，而是往「把它修好」那边走一步：没装就开一个会话跑安装命令， 你看着它装；没密钥就弹一个粘贴框，附带一个去哪儿拿密钥的链接。

Keys are checked against the real endpoint before they're saved, so paste half a key and you find out immediately — not ten seconds later, inside a session full of English error text. 密钥存下来之前会拿真的接口验一遍：粘贴了半截，你当场就知道， 而不是十秒钟后在一屏英文报错里发现。

—

Keys live in ~/.dct/secrets.toml, mode 0600, nowhere near the profile files — those you can copy between machines or hand to a colleague. Want your own agent? Drop a TOML file in ~/.dct/profiles/. Nothing to rebuild, nothing to restart. 密钥放在 ~/.dct/secrets.toml，权限 0600，跟 profile 文件离得远远的—— 后者你可以随便拷到别的机器上、或者发给同事。想加自己的 agent？往 ~/.dct/profiles/ 里丢一个 TOML 文件，不用重编，也不用重启。

away from the desk人不在电脑前

It can find you on your phone 它能在手机上找到你

Pair a Telegram bot and dct pushes one message when a session finishes, fails or disappears — several things that happened while you were away arrive merged into one, not as forty notifications. Reply to a push and your answer is typed into that session for you. 配一个 Telegram bot，会话干完了、报错了、自己没了，dct 就推一条消息过来—— 你不在的这段时间里发生的好几件事会合并成一条，而不是四十条推送。 长按回复一条推送，你说的话就被敲进那个会话里。

The bot's username is public, so the first person to write after you fill in the token becomes the owner, and everyone else is discarded forever. bot 的用户名是公开可搜的，所以规则是：令牌填完之后第一个发消息的人成为主人， 其余所有人的消息永远丢弃。

install装上它

Two commands, either platform 两条命令，两个平台

You need Rust 1.80 or newer and git. On macOS and Linux you also need a C toolchain, because the TLS stack compiles some C. 需要 Rust 1.80 或更新，以及 git。macOS 和 Linux 上还需要一套 C 工具链， 因为 TLS 那一层要编一点 C。

macOS · Linux
git clone https://github.com/gaolei8888/dc-terminal
cd dc-terminal
./scripts/install.sh
Windows · PowerShell
git clone https://github.com/gaolei8888/dc-terminal
cd dc-terminal
scripts\install.cmd

Windows is native — no WSL. No Visual Studio Build Tools either: winget install Rustlang.Rustup plus the WinLibs mingw is enough, and the installer checks for the one piece rustup's own bundled mingw is missing before it starts compiling. Windows 是原生的，不用 WSL。也不需要 Visual Studio Build Tools： winget install Rustlang.Rustup 加一套 WinLibs mingw 就够， 而 rustup 自带那套 mingw 缺的那一个东西，安装脚本会在开始编译之前先替你查出来。

Then run dct inside any git project. 然后在任何一个 git 项目里敲 dct。

Things that will annoy you 会让你不爽的地方

!

The four vendor endpoints have never been tested with a real account. Kimi, GLM, DeepSeek and Qwen API are copied out of public documentation. A key can verify fine and the session still fail to start. Treat them as unverified. 那四个厂商接口从来没用真账号跑通过。Kimi、GLM、DeepSeek、Qwen API 都是照着公开文档抄下来的。密钥验得过，会话照样可能起不来。当它们是没验证过的。

!

Permissions are auto-accepted, so an agent can write outside the project directory. Those writes are outside the snapshot, and undo won't bring them back. 所有确认都是自动同意的，agent 可以往项目目录外面写东西。 那些改动不在快照里，撤销拿不回来。

!

Two agents in one project will fight over the same files. Different projects, no problem. 同一个项目里开两个 agent，它们会抢同一批文件。不同项目就没这问题。

!

A session is stuck with the agent it was born with. There's no swapping Claude for Codex halfway through — the whole conversation lives inside that process. 会话生下来是哪个 agent 就是哪个，中途换不了——整段对话就活在那个进程里。

!

Automatic session names need an [llm] backend configured, and most people don't have one. Without it the name falls back to the first thing you typed; nothing errors, nothing interrupts. 自动给会话起名字需要配一个 [llm] 后端，多数人没有。 没有的话名字就退回你打的第一句话；不报错，也不打断你。
