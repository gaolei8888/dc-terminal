# dct 多语言（第一期：机制 + 中英全量）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dct 的界面、命令行帮助、守护进程返回的错误全部可翻译，第一期把英文和中文两种做全，界面里按 `l` 可切换并记住。

**Architecture:** 四层各自独立可测——`i18n.rs` 只管「哪种语言」和「这句话怎么说」（纯函数，不认识界面也不认识守护进程）；`settings.rs` 只管把选择写进磁盘；`proto.rs` 把守护进程的错误从人话字符串换成错误码，**组句只发生在界面进程**；`ui.rs` 只管取词和交互。

**Tech Stack:** 沿用现有依赖，**一个新依赖都不加**（`serde` / `serde_json` / `ratatui` / `crossterm` / `anyhow` 都已在 `Cargo.toml` 里）。

**Spec:** `docs/superpowers/specs/2026-08-03-dct-i18n-design.md`

## Global Constraints

- Rust ≥ 1.80，edition 2021，单 crate，二进制 `dct`
- **不引入 async 运行时**，也不加新依赖。阻塞 IO + 线程
- 锁一律经 `session::recover()` 处理 poison，不用裸 `.lock().unwrap()`
- **用户可见文案不出现 git / 终端黑话**（目标用户零编程经验）。错误说人话，不给栈追踪
- **代码注释、提交信息、测试里的断言说明一律中文**——本仓既有约定，不因为在做英文文案而改变
- 第一期 `Lang` 只有 `En` / `Zh` 两个变体。**不要提前加另外五种**：加变体的价值在于编译器逐条点名，提前加空壳等于把这个价值扔掉
- `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、全量测试必须通过
- 跑 cargo 前先 `export PATH="$HOME/.cargo/bin:$PATH"`（rustup 装在 `~/.cargo`，shell 配置没改）
- 测试统一 `--test-threads=1`（仓库既有约定）
- **测试里绝不读写真实环境变量**：`std::env::var` 是进程全局状态，测试之间会互相打架。解析函数收一个查询闭包，测试传假表
- ratatui 画中文这种宽字符时只写首格、第二格保留旧值。**同一个 `TestBackend` 连画两帧再断言，上一帧的残字会拼进来**。要断言多个视图就每次新建 `Terminal::new(TestBackend::new(...))`
- `tests/client_timeout.rs::timeout_does_not_desync_the_protocol` 是既有的时序敏感测试，串行跑整套时偶发失败、单独跑通过。不要改它
- 每个任务结束必须提交

```rust
use serde::{Deserialize, Serialize};

/// 界面语言。
///
/// 第一期只有英文和中文。加第八种语言那天，编译器会把每一条没翻的文案都点名——
/// 这正是用枚举而不是配置文件的全部理由，所以**不要**提前加空壳变体。
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum Lang {
    En,
    Zh,
}

impl Lang {
    /// 语言自己的名字。误切到看不懂的语言时，用户还能认出自己那一行切回来。
    pub fn native_name(self) -> &'static str {
        match self {
            Lang::En => "English",
            Lang::Zh => "中文",
        }
    }

    /// 存进 settings.json 的短码。和枚举顺序无关，改了枚举也不会让老文件失效。
    pub fn code(self) -> &'static str {
        match self {
            Lang::En => "en",
            Lang::Zh => "zh",
        }
    }

    pub fn from_code(s: &str) -> Option<Lang> {
        match s {
            "en" => Some(Lang::En),
            "zh" => Some(Lang::Zh),
            _ => None,
        }
    }

    /// 选择器按这个顺序列出。
    pub fn all() -> &'static [Lang] {
        &[Lang::En, Lang::Zh]
    }
}

/// 定最终用哪种语言。优先级从高到低：
/// 1. `DCT_LANG` —— 单次强制，调试用，不写盘
/// 2. `saved` —— 用户在界面里选过的
/// 3. 系统 locale：`LC_ALL` → `LC_MESSAGES` → `LANG`
/// 4. 英文
///
/// `env` 是查询闭包而不是直接读 `std::env`：环境变量是进程全局状态，
/// 测试里改它会跨测试打架。生产代码传 `&|k| std::env::var(k).ok()`。
pub fn resolve(saved: Option<Lang>, env: &dyn Fn(&str) -> Option<String>) -> Lang {
    // 认不出就当没写。DCT_LANG 是调试开关，为一个拼错的值报错拦住启动不值得。
    if let Some(l) = env("DCT_LANG").and_then(|v| Lang::from_code(v.trim())) {
        return l;
    }
    if let Some(l) = saved {
        return l;
    }
    for k in ["LC_ALL", "LC_MESSAGES", "LANG"] {
        match env(k) {
            // 空串当没设。有些环境会把用不上的 locale 变量设成空。
            Some(v) if !v.trim().is_empty() => return from_locale(&v),
            _ => {}
        }
    }
    Lang::En
}

/// 只认主码：`zh_CN.UTF-8` → `zh`。地区和字符集一律丢掉。
/// 认不出的（含 `C` / `POSIX`）回退英文——英文是唯一能保证词条齐全的兜底。
fn from_locale(v: &str) -> Lang {
    let primary = v
        .trim()
        .split(['_', '-', '.'])
        .next()
        .unwrap_or("")
        .to_lowercase();
    Lang::from_code(&primary).unwrap_or(Lang::En)
}
```

丢了无所谓，所以它的 `save()` 吞掉一切错误；语言是用户明确做出的选择，写不进去必须

```rust
use anyhow::{Context, Result};
use serde::{Deserialize, Serialize};
use std::path::{Path, PathBuf};

use crate::i18n::Lang;

/// 盘上格式。包一层对象而不是直接存字符串，是为了将来加设置项时老文件仍能读。
#[derive(Default, Serialize, Deserialize)]
struct Disk {
    #[serde(default)]
    lang: String,
}

/// 存放位置跟着 socket 走，和 `projects::store_path_for_socket` 同一套推导：
/// 生产是 `~/.dct/settings.json`，集成测试把 socket 放临时目录就自动隔离，
/// 不会去动你真实的那份。
pub fn settings_path_for_socket(socket: &Path) -> PathBuf {
    match socket.parent() {
        Some(d) => d.join("settings.json"),
        None => PathBuf::from("settings.json"),
    }
}

/// 盘上存了什么。缺失、损坏、语言码不认识，一律 `None`——
/// 「盘上没有可用的选择」是一种情况，不是三种。
/// 决定最终用哪种语言的是 `i18n::resolve`，不是这里。
pub fn load_lang(path: &Path) -> Option<Lang> {
    std::fs::read_to_string(path)
        .ok()
        .and_then(|s| serde_json::from_str::<Disk>(&s).ok())
        .and_then(|d| Lang::from_code(&d.lang))
}

/// 落盘失败要让调用方知道：语言是用户明确做出的选择，写不进去必须说一声，
/// 否则用户下次开 dct 发现语言变回去了，不知道该怪谁。
pub fn save_lang(path: &Path, lang: Lang) -> Result<()> {
    let parent = path
        .parent()
        .context("设置文件没有上级目录，不知道该写到哪")?;
    std::fs::create_dir_all(parent).context("建不了存放设置的目录")?;
    let json = serde_json::to_string(&Disk {
        lang: lang.code().to_string(),
    })
    .context("设置转不成 JSON")?;
    // 原子写：先写同目录的临时文件再 rename。直接覆写的话，写到一半断电
    // 会留下半截 JSON，下次 load 解析失败就把设置丢了。
    let tmp = path.with_extension("json.tmp");
    std::fs::write(&tmp, json).context("设置写不进磁盘")?;
    std::fs::rename(&tmp, path).context("设置文件替换失败")?;
    Ok(())
}
```

`tempfile` 已在 `[dev-dependencies]` 里，不需要改 `Cargo.toml`。

### Task 3: 宽度计算与自适应提示条

**Files:**
- Modify: `src/ui.rs`

**Interfaces:**
- Consumes: 无
- Produces:
  - `ui::display_width(s: &str) -> usize`
  - `ui::pad_to_width(s: &str, width: usize) -> String`
  - `ui::HelpItem { pub key: &'static str, pub label: &'static str, pub prio: u8 }`
  - `ui::fit_help(items: &[HelpItem], width: usize) -> String`
  - 现有 `truncate` 改为复用 `display_width`

**说明：** 七种语言的长度差得很远。底部提示现在放不下就从右边直接截，越靠后的键越先
消失——`q 退出` 首当其冲，而「怎么退出」恰恰是最不该丢的一条。`fit_help` 改成按优先级
丢：`prio` 数字越大越先被丢掉。

顺带修掉一个既有毛病：看板第一列用 `{:<8}` / `{:<10}` 这类按**字符数**补齐，而 `truncate`
按**显示宽度**截断。中文「干活中」3 个字符、显示宽 6，右边那列就被推歪。

```rust
/// 一个字符在终端里占几格的近似规则：U+1100 以上按双宽算。
/// 这覆盖了中日韩，也把西欧语言的重音字母（都在 U+1100 以下）正确算成单宽。
/// 不引入 unicode-width 依赖——本仓至今一个非必要依赖都没加。
fn display_width(s: &str) -> usize {
    s.chars()
        .map(|ch| if (ch as u32) > 0x1100 { 2 } else { 1 })
        .sum()
}

fn truncate(s: &str, max: usize) -> String {
    let mut w = 0;
    let mut out = String::new();
    for ch in s.chars() {
        let cw = if (ch as u32) > 0x1100 { 2 } else { 1 };
        if w + cw > max {
            out.push('…');
            return out;
        }
        w += cw;
        out.push(ch);
    }
    out
}

/// 按**显示宽度**补空格。`format!("{:<8}", s)` 补的是字符数——
/// 「干活中」3 个字符、显示宽 6，用 `{:<8}` 会多补 5 格，把右边那列推歪。
fn pad_to_width(s: &str, width: usize) -> String {
    let w = display_width(s);
    if w >= width {
        return s.to_string();
    }
    let mut out = String::from(s);
    out.push_str(&" ".repeat(width - w));
    out
}

/// 底部提示条里的一项。`prio` 数字越大越先被丢掉。
pub struct HelpItem {
    pub key: &'static str,
    pub label: &'static str,
    pub prio: u8,
}

/// 把提示项拼成一行，放不下就从优先级最低的开始丢，丢过就在末尾加 `…`。
///
/// 为什么不让译文写短：七种语言长度差得很远，德语的「回滚」是 Zurücksetzen。
/// 强制写短只能靠缩写（`Zurücks.`），而目标用户是零编程经验的成年人，
/// 缩写对他们不友好。宁可少显示几项，留下的每一项都要看得懂。
fn fit_help(items: &[HelpItem], width: usize) -> String {
    const SEP: &str = "  ";
    let render = |keep: &[bool], dropped: bool| -> String {
        let mut parts: Vec<String> = Vec::new();
        for (i, it) in items.iter().enumerate() {
            if keep[i] {
                parts.push(format!("{} {}", it.key, it.label));
            }
        }
        let mut s = parts.join(SEP);
        if dropped {
            if !s.is_empty() {
                s.push_str(SEP);
            }
            s.push('…');
        }
        s
    };

    let mut keep = vec![true; items.len()];
    let mut dropped = false;
    loop {
        let s = render(&keep, dropped);
        if display_width(&s) <= width {
            return s;
        }
        // 丢掉还留着的项里 prio 最大的；同 prio 丢靠后的那个
        let victim = items
            .iter()
            .enumerate()
            .filter(|(i, _)| keep[*i])
            .max_by_key(|(i, it)| (it.prio, *i))
            .map(|(i, _)| i);
        match victim {
            Some(i) => {
                keep[i] = false;
                dropped = true;
            }
            // 一项都不剩了还是放不下，说明窗口窄到连 `…` 都放不下
            None => return truncate(&render(&keep, dropped), width),
        }
    }
}
```

```rust
    Git(String),
```

**3d. `src/ui.rs`** —— 加组句函数：

```rust
/// 用户刚才按了什么。同一个错误码在不同操作下要说不同的话——
/// 守护进程报的是成因，界面才知道用户想干什么。
#[derive(Clone, Copy)]
pub enum ErrorCtx {
    Generic,
    Undo,
    Diff,
}

fn error_text(code: &ErrorCode, lang: Lang, ctx: ErrorCtx) -> String {
    match code {
        ErrorCode::NoSuchProfile(n) => i18n::msg::no_such_agent(lang, n),
        ErrorCode::DirNotFound(d) => i18n::msg::dir_not_found(lang, d),
        ErrorCode::NotAGitRepo(d) => i18n::msg::not_version_controlled(lang, d),
        ErrorCode::NoSuchSession(id) => i18n::msg::no_such_session(lang, *id),
        ErrorCode::NoCheckpoint => i18n::msg::no_checkpoint(lang),
        ErrorCode::NotAnAgentSession => match ctx {
            ErrorCtx::Undo => i18n::msg::cannot_undo_here(lang),
            ErrorCtx::Diff => i18n::msg::no_change_record(lang),
            ErrorCtx::Generic => i18n::msg::no_change_record(lang),
        },
        ErrorCode::BadRequest(d) => i18n::msg::bad_request(lang, d),
        ErrorCode::Git(d) => i18n::msg::operation_failed(lang, d),
    }
}
```

所有 `Ok(Response::Error(e)) => Msg::err(e)` 的写法改成
`Ok(Response::Error(e)) => Msg::err(error_text(&e, lang, ErrorCtx::Generic))`；
`u` 的那处传 `ErrorCtx::Undo`，`d` 的那处传 `ErrorCtx::Diff`。
`act()` 的签名要加 `lang` 和 `ctx` 两个参数。
