# dct：把用户说的话送进会话（语音中继 v0）

日期：2026-10-04
状态：设计 + 实施要求合一（用户已确认方向：章鱼是你和会话说话的入口，一个章鱼；先做「你说话、送进会话」这一半）。
前提：dco 语音已装好并验收了中文识别（`dco call hear` 返回 `{utterances:[{seq,text,confidence,language,source:"voice",trigger}]}`）。dco 只听，不执行；执行与否、送给谁，由 dct 决定。

## 目标

用户点章鱼说一句话，dct 把它当成用户亲手打的字，送进他最近对话的那个会话（claude / codex / qwen …）。用户随时能看到「听到了什么、送给了谁」，并在 2 秒内用一句话取消。

**不做（这一轮）：** 唤醒词、会话回复念出来（要等 dco 的 `speak`）、识别器提示词、跨电脑路由、任何新的 UI。

## 原则（必须守住）

1. **语音永远不算授权。** 人声可以被电视或别人冒充。语音文字不能用来回答「同意/批准/确认」类提示：
   - 目标会话此刻如果在等用户批准（会话状态是需要用户处理的那一种），**一律不送**，在终端打印「这一步要你在键盘上确认」。
   - 整句只是「好 / 是 / 嗯 / 确认 / 同意 / 可以 / 行 / yes / ok / y」这类单独的确认词，**一律不送**（同样提示）。
2. **dct 不替用户改写他的话。** 除了第 4 条的识别纠错，原文送进去，前面只加固定前缀 `（语音输入，可能有识别错误）`，让 agent 知道要宽容。
3. **dct 只放通用代码。** 不写任何游戏专属内容。「章鱼」的误识别词表是产品名相关，不是游戏专属，放配置文件，可改。
4. **本机、不落盘声音。** dct 只处理 dco 给的文字。日志只记文字，不记声音。

## 组成

新命令：`dct voice`（前台循环；以后由守护进程或 dc.ai 拉起，那是以后的事）。不碰守护进程本身，通过它现有的 unix socket 请求 `Request::Input { id, text }` 送字（`src/daemon.rs`、`src/proto.rs`）。

循环（每轮）：
1. `dco call hear {since_seq, wait_ms: 20000}` 取新话（用本仓库里调用 dco 的现成办法，不新造；先看 `crates/dct-game/src/dco.rs` 和 `src/game/` 里怎么调）。
2. 对每句话依次：**纠错 → 过闸 → 路由 → 预告 → 等取消 → 送出**。
3. 取不到（dco 没装、语音关）时，打印一句大白话并退出码非 0，不死循环。

### 纠错（纯函数）

`~/.dct/voice.toml`（没有就用内置默认）：
```toml
[alias]            # 识别器常把这个词写成别的
章鱼 = ["张瑜", "张宇", "章玉", "张羽"]
```
规则：只替换整词出现的别名；原文和纠正后的都写进日志。**不要**扩成通用同音字替换。

### 过闸（纯函数 + 会话状态）

按「原则 1」：
- 置信度 < 0.5：不送，打印「没听清，再说一遍？」。
- 仅确认词：不送。
- 目标会话在等批准：不送。
- 一次最多送一句，两次之间至少隔 2 秒（限速）。

### 路由（纯函数）

- 话以「给<名字>说」「对<名字>说」「告诉<名字>」开头，且名字（忽略大小写、忽略空格和连字符）匹配某个会话名或 `#编号` → 送给它，并去掉这个开头。
- 否则送给 `last_active` 最大的那个会话（`src/session.rs` 里 `send_input` 会刷新它；如果 `dct ps --json` / 现有请求里没暴露，加一个只读字段，**不要**改刷新规则）。
- 没有任何会话：不送，打印「现在没有开着的会话」。
- 名字匹配到多个：不送，打印「有几个叫这个名字的会话，说编号」。

### 预告和取消

- 决定要送之前，在终端打印：`听到：「…」 → 发给：<会话名>（2 秒内说「取消」可以不发）`；同时尽力用 dco 的说明条显示同样的字（如果 `show_status` 或现有工具能带文字就用，不能就只打印，**不要**为此改 dco）。
- 等待 2 秒期间继续取 `hear`：如果来了「取消 / 算了 / 不要发 / 别发」这类话（整句），丢掉这一句并打印「已取消」。取消的话本身不送给任何会话。
- 2 秒到了才送。

### 日志

`~/.dct/voice.log`：每行一条 JSON：`{t, text_raw, text_fixed, confidence, target, action: "sent|cancelled|blocked_confirm|blocked_prompt|low_confidence|no_session|ambiguous", reason}`。只文字。文件权限 0600，目录由现有 `~/.dct` 规则决定。

## 测试（必须）

纯函数全部有单元测试，会话和 dco 用假的：
- 纠错：别名整词替换；子串不替换；无别名不动。
- 过闸：置信度 0.49 / 0.5；单独确认词的各种写法（含「好的」「嗯嗯」要不要挡：只挡**整句**是确认词的，「好的，继续做」不挡）；等批准的会话不送；限速。
- 路由：各种开头；名字大小写和连字符；多个匹配；无会话；`#编号`。
- 预告和取消：假时钟，2 秒内来「取消」不送；来别的话不影响；2 秒到才送；取消的话本身不送。
- 回路：dco 取不到时的退出码和提示；`since_seq` 不重复取同一句。
- 变异测试（每一条改掉后必须有测试失败）：①去掉「等批准不送」 ②去掉置信度闸 ③去掉「整句确认词不送」 ④把取消窗口改成 0 秒 ⑤路由默认改成第一个会话而不是 last_active 最大的。

## 验收（真机，需要用户在场，由控制器做，不是实施者）

1. 用户点章鱼说「你好，请帮我看一下现在的目录」，终端出现预告，2 秒后字进了他最近用的会话。
2. 说「取消」能挡住。
3. 在一个等批准的会话上说「同意」：不送，提示去键盘。
4. 说「给 dc-octo 说，……」：送到对应会话。

## 已知限制 / 以后

- 要靠用户点章鱼；唤醒词是下一步（dco 在做评估实验）。
- 没有回话：会话的回复念出来依赖 dco 的 `speak`，以及给会话的「【说】」一行约定，另做。
- 识别把「章鱼」写成人名只做了别名纠错，没做识别器提示词。
- 只在 Mac 上有意义（dco 只有 Mac 版）；非 Mac 编译要能通过（`#[cfg(unix)]` 之类，照 `src/game/scene.rs` 的做法）。
