### 信息定位（研究候选，非验收通过）
- TypeSafe Jev 1.14 提供云端结构化决策与实验视觉/box 接口；**官方 Jev 权重未确认开放**，不能将 API/SDK 开源等同于模型可离线运行；调用价格、图片定价、延迟应以账户与最新官方文档重新核实。
- OpenDecision：社区开源候选，声称支持文本/图片、结构化 Choice/Score 等；验证其真实视觉路径（如 SigLIP2）、许可、依赖、结果以及是否能进行精确目标定位；**图片分类不等于可点击坐标定位**。
- JevK5：社区本地 GGUF 文本决策候选（含 2B/4B 量化）；不能直接当作视觉模型；核验模型权重来源、license、可用推理后端和实际性能。
- Laya / Laya-MLX：文本快速决策候选，Apple Silicon 可单独测量；**此前 dco 在 2026-09-30 的零样本实验已决定近期不再投入 Laya**，本信息不推翻已有结论，除非新测试明确证明优势。
- NeoHorse-Jev-4B：社区多模态决策候选，需核实权重、显存、输入限制和真实 GUI 成功率。
- HN 评论中的速度、准确率、成本等均是社区报告，**不可视为我们自己的 benchmark 或交付承诺**。

### 建议统一的 Decision Engine 接口
- 输入：结构化任务状态、动作候选集合、可选屏幕截图/视觉特征、任务上下文、权限边界、观测时间戳。
- 输出：所选动作、分数/置信度（先校准）、候选排序、模型标识、耗时、是否需升级大模型、解释/依据（可选）。
- 路由：确定性流程/规则优先；窄域重复判断走本地小模型；复杂策略交给大模型；不能验证或低置信度时停下、重观测或升级。
- **安全永远由现有权限/票据/隐私/付款/不可撤回拦截机制决定，模型不得降级授权；新模型只提议动作，不能直接越权执行。**
- 图片处理默认本地；发云端前明确用户知情和授权；记录新旧观测 ID 防止截图过期导致误操作。
- 先做插件化实验，不直接替换目前稳定的 OCR、accessibility、read_grid 和规则路径。

### 验证计划（不代表已经执行）
1. 在相同截图/状态/动作集合下对照：确定性规则、现有本地模型、OpenDecision、JevK5(+独立视觉前端)、NeoHorse、Jev API。
2. 测试按钮/弹窗/表单/页面跳转以及真实游戏状态；对视觉任务分别测状态判断、框定位、执行后确认。
3. 记录：端到端 P50/P95 延迟、准确率、100 次连续任务成功率、误动作及安全拦截、CPU/内存/显存峰值、网络用量及成本。
4. 优先覆盖用户基准机 Mac M2 16GB 与 Windows i7/RTX 2070 Max-Q 8GB/32GB；M5 Max 64GB 仅作开发对照，数据必须注明设备。
5. 根据实测和原有负面结果选择是否继续；没有性能/质量收益就不引入新常驻模型。

### 负责人交接
- DCT：定义模型路由与统一协议、任务级降级与超时，保持高阶规划/授权边界独立。
- DCO：负责获取屏幕/设备观测、调用可选快速判断、执行动作后验证和错误恢复；不把模型判断当成权限凭据。
- 下一步应先出小范围实验报告和复现脚本；**当前为技术研究建议，非已实现功能**。
