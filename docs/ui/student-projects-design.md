# 学生项目保存与下载 · UI 方案

这是设计方案及可点击原型，尚未接入真实存储或部署。原型的姓名、文件、保存状态和容量均为示例。

## 默认规则

按“每次练习结束后清理运行环境，但保留学生作品”设计，具体清理时机待确认。

- 项目：代码、素材、说明、命名版本，归学生个人所有。
- 运行环境：本次 agent、终端进程、运行程序、临时缓存，可以在结束练习时释放。
- 关闭浏览器不等于结束练习；结束练习不等于删除项目。
- 工作区没有清理前，不应该要求学生靠手动下载才能避免丢文件。

当前部署的 `/home/dc/work` 已挂载持久化卷；仅关闭浏览器、重启或常规重建容器不会自动删除这个卷里的文件。删除卷、显式删目录，或者把作品写在持久化目录之外，仍可能丢失。若现场确实“每次项目都会被清掉”，需要另外核对实际清理流程，不能只加一个“保存”按钮掩盖问题。

## 页面与操作

| 位置 | UI | 行为 |
|---|---|---|
| 项目页顶部 | 项目名；保存中／已保存时间／保存失败 | 状态必须来自服务端持久化确认，不能用浏览器计时器当真实保存结果 |
| 右侧「项目与文件」 | 文件列表；上传；下载项目 | 替换现有仅上传的侧栏；点击文件查看详情并下载 |
| 文件每行 | 下载 | 下载单个原始文件；目录提供打包下载 |
| 下载项目 | 文件名、体积、导出内容；保存最新文件并下载 | 导出一致版本的 ZIP，完成后项目仍保留 |
| 保存的版本 | 保存一个版本；版本列表；下载；从此版本继续 | 保留重要阶段；恢复默认创建副本，不覆盖现有修改 |
| 我的项目 | 项目卡片、最后保存时间、容量；继续项目；下载 ZIP | 学生下次登录首先能找到自己的作品 |
| 我的项目 | 新建项目；导入项目 ZIP | ZIP 导入新项目；同名提示，不覆盖旧项目 |
| 项目页顶部 | 结束本次练习 | 解释哪些内容保留、哪些进程结束；确认后保存并释放运行环境 |
| 项目卡片的更多操作 | 删除项目 | 与结束练习分开；移到回收站；保留期明确显示 |

移动端：终端全宽；「项目与文件」作为可展开面板，关闭后恢复终端焦点并重新计算尺寸。桌面端保留可折叠侧栏，不让文件操作抢走终端输入焦点。

## 保存、下载、清理顺序

### 日常工作

新建或打开项目 → 文件写入学生的持久化项目目录 → 服务端确认后显示“已保存”。命名版本用于保留阶段，不替代自动保存。不声称保存正在运行的程序内存、尚未提交的终端输入或 agent 的思考状态。

### 下载

选择单文件或整项目 → 确认导出范围 → 服务端从一致的文件版本准备下载 → 浏览器下载。

整项目默认包含代码和上传素材；排除账号密钥、`.env` 等敏感配置、依赖包、缓存和 Git 内部目录。导出前展示包含与排除的分类；需要运行的配置提供无密钥的示例。对无法自动识别的文件允许用户检查导出范围。

大项目显示“准备下载，已处理 N 个文件”，失败可重试；只有完整压缩包生成后才提供下载。不把“浏览器开始下载”当成“学生已经保存到电脑”的证据，更不能据此删除服务器项目。

### 结束练习

确认结束 → 暂停／停止本次写入任务并等待收尾 → 保存最终文件版本到个人项目库 → 校验保存成功 → 释放运行环境 → 回到「我的项目」。

保存失败、磁盘不足或无法确认一致版本：保留现有工作区，显示“尚未保存，未清理”，提供重试和可用的下载入口。强制停止运行任务需说明影响。管理员清理任务也必须遵守保存成功后才能删除工作副本的顺序。

如果课堂规则要求工作目录每次清空，应清空已经归档的工作副本；个人项目库位于清理范围之外。项目保留期限另设，不与容器生命周期绑定。

## 必要的后端约束

1. 每名学生有独立身份和项目目录。当前共享同一条工作区链接不能表达多个学生的所有权，不能直接作为全班的个人项目库。
2. 项目库不放在会被清理的运行环境里。持久化存储、版本、备份各有用途；同一磁盘上的一个卷不是备份。
3. 列文件、上传、下载、打包都校验学生和项目权限，限制在项目根目录；防止路径穿越、符号链接越界、恶意压缩包解压越界及超额占用磁盘。
4. 3 GiB 是每名学生的运行内存限制。文件磁盘配额、版本保留数量、回收站与归档期限需独立配置，并在 UI 显示。
5. 清理和备份均保留状态记录；上传失败不留半文件，重试不重复覆盖。

## 首期范围

先做个人项目目录、文件列表、单文件与整项目下载、准确的保存状态、保存后结束练习、项目库继续入口。命名版本、ZIP 导入和回收站可作为下一步；首期若尚无回收站，UI 不提供项目删除按钮。

## 原型验证

`student-projects.html` 可本地浏览器直接打开。已检查下载弹窗、保存后结束流程、从项目库继续，以及 390px 手机宽度无横向溢出。原型只模拟交互，不执行真实保存、清理或下载。
